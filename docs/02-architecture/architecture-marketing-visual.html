Marketing Data Fabric

Kiến trúc Marketing Data Fabric sử dụng medallion data plane (raw → unified → marts) kết hợp active-metadata control plane. Hai diagram trình bày luồng dữ liệu từ source tới các serving domain và runtime topology giữa Streamlit, Mock API, Spark jobs, Airflow, OpenMetadata và PostgreSQL.
